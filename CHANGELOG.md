# Changelog

## 1.0.0 - 2026-09-10

First release built by GitHub Actions from this repository. Same translation content and mod version as the original hand-built installer from 2026-03-29.

- Full source published: mod (C#, translation XML, font bundle), installer source, UI assets, build script and CI.
- The `.exe` is no longer committed to the repository. Every release is built from the source in this repository and published on the Releases page together with `SHA256SUMS.txt`.
- Releases also include `arabic.OWArabicTranslation.zip` for manual installation through the Outer Wilds Mod Manager.
- Translation: 2424 dialogue entries, Arabic letter shaping and right-to-left line handling in `ArabicTranslation.dll`, Noto Sans Arabic font bundle.
- SHA-256 of the original hand-built `OWArabicTranslation_Installer.exe` that was committed to this repository before this release: `6ed16478cdedfc969dac91f694fa5a1f4b6285a3088d8edcec811b928c92c1a3`
